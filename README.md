## Control every app's volume

Every app that's playing sound gets its own slider, so you can balance a game, a video call and your music without opening Windows settings.

- **Drag a slider** to change that app's volume.
- **Click an app's icon** to mute or unmute it.
- **Click an app's name** to rename it to something friendlier (handy for apps with confusing names).
- **Click the eye** to hide an app you never want to see. You can bring it back at any time from **Settings > Hidden Apps**.
- **Missing an app?** Apps only appear once they start playing sound. Click the refresh arrow next to **Active Apps** to check again.

  <tr>
    <td align="center"><img src="docs/images/hide-app.png" width="300" alt="The hide button next to an app" /><br/><sub>Click the eye to hide an app</sub></td>

> **Background apps:** some programs play sound without an open window (for example, apps that sit in the system tray). SoundBar leaves these out to keep the list tidy. To show one, open **Settings > Background Apps** and click **Allow**.

## Control it from your phone

SoundBar has a built-in phone remote. Change volumes, skip songs, mute your microphone or switch speakers from the sofa, with nothing to install from an app store.

**Setting it up (about a minute):**

1. Make sure your phone and PC are on the **same Wi-Fi**.
2. Click the **phone icon** at the top of SoundBar.
3. Click the big **power button**. The first time, Windows will ask for permission. Click **Yes**. You only need to do this once.
4. A **QR code** and a **4-digit code** appear. Point your phone's camera at the QR code and open the link.
5. Type the **4-digit code** on your phone. That's it, you're connected.

> **Tip: make it feel like a real app.** Once connected, add it to your home screen. On iPhone, tap **Share > Add to Home Screen** in Safari. On Android, tap the **⋮ menu > Add to Home screen** in Chrome.

> **Keeping it safe:** you get a new 4-digit code every time you turn the remote on. Anyone who guesses wrong 5 times is locked out for a while. SoundBar also warns you before turning on if you're on public Wi-Fi (like a café or hotel). Only use the remote on networks you trust.

## Keyboard shortcuts

Change the volume of the app you're using **without leaving it**. This is perfect for games and video calls. "The app you're using" means whichever window you're currently in.

| Shortcut | What it does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>↑</kbd> | Turn the app you're using up |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>↓</kbd> | Turn the app you're using down |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>M</kbd> | Mute or unmute the app you're using |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>I</kbd> | Mute or unmute your microphone |

You can change any of these in **Settings > Global Hotkeys**. SoundBar also highlights the app your shortcuts will control, so you always know what you're changing. You can turn this highlight on or off with **Active App Highlight** in **Settings > Appearance**.

## Handy extras

### Always on top
Click the **pin** at the top of the window to keep SoundBar in front of everything else. Click it again to turn it off.

<p align="center">
  <img src="docs/images/always-on-top.png" width="300" alt="The Always on Top button" />
</p>

### Start with Windows
Turn on **Run at Startup** in **Settings > System Integration** and SoundBar will be ready whenever you turn on your PC. You can also add a shortcut to your desktop from here.

<p align="center">
  <img src="docs/images/startup.png" width="300" alt="The Run at Startup and Create Desktop Shortcut options" />
</p>

### Do Not Disturb
Silence all Windows notification and system sounds with one switch in **Settings > Do Not Disturb Mode**. Your music and games keep playing. To change which sounds Windows plays, use the **Open System Sounds** button.

### Hearing protection
If your volume stays above 85% for a long time, SoundBar can show a friendly warning to protect your ears. Turn it on in **Settings > Hearing Protection**.

### Automatic updates
SoundBar checks for a new version each time it starts. When one is available, an **Update Available** button appears at the top. Click it once and SoundBar updates itself. Your settings and wallpapers are kept.

To see what changed, click the version number in the bottom corner or open **Settings > About & Updates**.

## How to install

**You'll need:** a 64-bit PC running Windows 10 (version 1809 or newer) or Windows 11.

### Option 1: Install with Winget (recommended)
Winget is Windows' built-in app installer. It also makes updating easy.

1. Click the **Start** button, type **Terminal** (or **PowerShell**) and open it.
2. Copy and paste the line below, then press **Enter**:

```powershell
winget install levon2805.SoundBar
```

### Option 2: Download it
SoundBar is a single folder. There's nothing else to install.

1. Go to the [**Releases**](../../releases) page.
2. Download the latest **`SoundBar.zip`**.
3. Right-click the zip, choose **Extract All**, and put the folder anywhere you like.
4. Open the folder and double-click **`SoundBar.exe`**.

> **Seeing a "Windows protected your PC" message?** This is normal for new apps from independent developers. Click **More info**, then **Run anyway**. You'll only see it the first time.

## Common questions

<details>
<summary><b>An app isn't showing up in the list</b></summary>

Apps only appear once they're actually playing sound. Start playing something, then click the refresh arrow next to **Active Apps**. If it still doesn't appear, check **Settings > Hidden Apps** (you may have hidden it) and **Settings > Background Apps** (click **Allow** to show it).
</details>

<details>
<summary><b>My phone won't connect</b></summary>

- Make sure your phone and PC are on the **same Wi-Fi** network. Phones on mobile data can't connect.
- Make sure the remote is turned on (the power button in **Mobile Companion**).
- If Windows has your network set to **Public**, set it to **Private** in **Windows Settings > Network & internet**. Only do this on your own home network.
- Typed the code wrong too many times? Wait a few minutes and try again.
</details>

<details>
<summary><b>Where are my settings saved?</b></summary>

In `%AppData%\SoundBar`. Paste that into the File Explorer address bar to open it. Your wallpapers are in the `Backgrounds` folder inside it. Updating SoundBar never touches this folder.
</details>

<details>
<summary><b>How do I uninstall SoundBar?</b></summary>

- **Installed with Winget:** run `winget uninstall levon2805.SoundBar` in Terminal.
- **Downloaded zip:** turn off **Run at Startup** in Settings, close SoundBar, then delete the folder.
</details>

<details>
<summary><b>Advanced settings</b></summary>

A few extra options (such as the network port the phone remote uses) can be changed by hand. Open **Settings > Advanced Configuration** and click **Open config.json**. Changes apply as soon as you save the file.

<p align="center"><img src="docs/images/advanced-config.png" width="285" alt="The Advanced Configuration settings" /></p>
</details>

## For developers

SoundBar is built natively with the Windows App SDK (WinUI 3) on .NET 8.

**Project layout:**
* `src/SoundBar/` contains the main WinUI 3 application (the phone remote's web app is in `src/SoundBar/wwwroot/`).
* `tests/SoundBar.Tests/` contains the xUnit automated tests.
* `ReleaseTools/` contains internal release and update-signing utilities.
* `docs/images/` contains the screenshots used in this README.

Open `SoundBar.slnx` or `src/SoundBar/SoundBar.csproj` in Visual Studio 2022 (or newer) to get started.

### Running automated tests
We use **xUnit** and **Moq** to test the internal services and debouncing logic.

The simplest way is Visual Studio's **Test Explorer** (`Test > Test Explorer > Run All Tests`).

From the command line, plain `dotnet test` can fail with `ExpandPriContent` MSBuild errors (a known Windows App SDK tooling quirk). Build with Visual Studio's MSBuild first, then run the tests without rebuilding:

```powershell
& "<Visual Studio>\MSBuild\Current\Bin\MSBuild.exe" tests/SoundBar.Tests/SoundBar.Tests.csproj -p:Configuration=Debug -p:Platform=x64 -restore
dotnet test tests/SoundBar.Tests/SoundBar.Tests.csproj -p:Platform=x64 --no-build
```
